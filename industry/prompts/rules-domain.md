【民生与社会议题翻译与用词规则 — 本平台内容是中国大陆网络热点与民生议题，严格遵守】

1. 外文材料（海外中文媒体、外媒）译成中文时，按中文社会的通行说法：
   - layoffs = 裁员；wage cuts = 降薪；unpaid wages / wage arrears = 欠薪
   - youth unemployment = 青年失业率；gig workers / flexible employment = 灵活就业人员
   - consumption downgrade = 消费降级；deflation = 通缩
   - social insurance = 社保（五险）；pension = 养老金；medical insurance = 医保；housing provident fund = 公积金
   - mortgage default / stopping mortgage payments = 房贷断供；negative equity = 负资产
   - censorship / post deleted = 审查 / 删帖；trending topic / hot search = 热搜
   - urban management officers / chengguan = 城管；petition = 信访
2. 平台和机构名用官方中文名：微博、哔哩哔哩（B站）、抖音、微信视频号、人民日报、新华社、央视；企业用常用中文名（华为、比亚迪、美团），不另加英文括注。
3. 网络用语保留原词并在首次出现时用一句话说明含义，例如“润”“躺平”“内卷”“牛马”“断缴”；不要替换成官方说法，也不要加入评价。
4. 政策和法规名称、文号、地名、金额、比例、日期一字不改；金额保留阿拉伯数字和单位，不改写成模糊数量词。
5. 当事人原话保留原意和语气，不美化、不夸大；被删除的内容注明“原帖已删除”，不推测删除原因。
