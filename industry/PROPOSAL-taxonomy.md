# 分类、标签和主题：已确认的五类

站长已确认下列五个类别。当前配置见 `industry/taxonomy.ts`、`industry/topics.json` 和 `industry/prompts/structure.md`。类别 key 会用于网址和公开接口；站点正式上线后不要随意修改。

## 已确认的类别（CATEGORIES，key 上线后不能改）

| key | label | 收什么 |
|---|---|---|
| `livelihood` | 民生 | 就业断层、裁员降薪欠薪、消费降级、资产缩水、房贷债务、教育育儿负担 |
| `institution` | 制度成本 | 社保医保养老公积金、税费、户籍等制度性成本与规则变化 |
| `controversy` | 舆论争议 | 删帖控评、起诉测评者、品牌与官方媒体互动、平台限流等标志性争议 |
| `enforcement` | 基层执法 | 政策在基层执行、执法冲突、罚款、拆迁、维权、信访 |
| `opinion` | 观点（commentary） | 评论、个人自述、访谈、海外视角分析 |

`RELEASE` 设为 `null`（这个领域没有统一的“发布数”指标）。

## 首标签（CATEGORY_TAGS）

民生、制度成本、舆论争议、基层执法、观点。另保留“其他”作为材料不足时的技术兜底。首标签对应主类别，避免类别和标签互相矛盾。

## 主题标签（TOPIC_TAGS）

就业/收入、消费、资产/房产、社保/医保、教育/育儿、舆论/删帖、执法/基层治理、政策/监管、个体叙述、数据/调查；裁员、欠薪、灵活就业、青年失业、房贷断供、降薪、涨价、退费、断缴、养老金、城管、罚款、拆迁、维权、限流、海外视角、政策解读。

## 实体（ENTITIES / ENTITY_TAGS）

当前只列微博、哔哩哔哩、抖音、微信视频号四个平台。用户在平台发内容，不等于平台自己发布了该内容。其他企业与媒体暂未加入实体名录，待实际信源和样本明确后再决定。

## 主题目录（topics.json）

分组 `company` 为“平台与机构”，`field` 为“民生议题”（就业、消费、资产、社保、执法、舆论），`genre` 为“内容形态”（调查、自述、观点、政策解读）。

## 内容类型（ITEM_TYPES）

框架代码（`packages/backend/src/editorial/`）用到这 7 个键名，所以保持不变；`prompts/selection-score.md` 和 `prompts/content-understanding.md` 按本站重新定义了每个键的含义。
